# AERIS Plugin

Python plugin for AyuGram / exteraGram.

**Status:** scaffold / каркас. Not yet functional.

The plugin will:
- Pair with AERIS Desktop on the same local network.
- Send supported media links and metadata.
- Expose playback controls from Telegram.
- Display receiver connection and playback status.

The plugin must target the official plugin SDK supported by the user's installed client version. SDK APIs and manifest fields will be verified against the official documentation before implementation.

See [AERIS Protocol](../protocol/PROTOCOL.md) for the shared protocol draft.

Официальная документация SDK: https://plugins.exteragram.app/docs
